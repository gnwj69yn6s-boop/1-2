# GenAI Multimodal Brand Advertisement

## 프로젝트 소개
이 프로젝트는 생성형 AI 도구를 활용하여 10초 이내의 브랜드 광고 영상을 제작하는 과제입니다.

## 브랜드
- 브랜드명: MoriSip
- 제품: 프리미엄 허브 탄산수
- 타겟: 바쁜 일상 속 짧은 휴식을 원하는 20~30대 직장인
- 핵심 메시지: 복잡한 하루, 한 모금으로 숲에 닿다.

## 최종 결과물
- 스토리보드 PDF: `storyboard/storyboard.pdf`
- 최종 영상: `final/final_ad.mp4`

## 사용 도구
- 이미지 생성: DALL·E 또는 Midjourney
- 비디오 변환: Runway 또는 Pika
- 오디오 생성: Suno 또는 Udio
- 음성 합성: ElevenLabs 또는 타입캐스트
- 편집: CapCut 또는 Premiere Pro

## 제작 파이프라인
1. 브랜드 아이덴티티 정의
2. 4씬 스토리보드 작성
3. 이미지 생성
4. 이미지 기반 비디오 변환
5. 배경음악 및 내레이션 생성
6. 편집 후 MP4 출력
